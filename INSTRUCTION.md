# Нормы-М — полная инструкция по установке и запуску

Инструкция для Windows (в конце — отличия для Linux/macOS).

---

## 0. Что должно получиться

```
C:\Projects\                      ← создайте эту папку сами
└── normy-m\                      ← появится после распаковки архива
    ├── package.json              ← отсюда запускаются ВСЕ команды npm
    ├── .env.example              ← шаблон настроек
    ├── .env                      ← ваши настройки (создадите на шаге 4)
    ├── db\
    │   ├── BDScript.sql          ← ваша БД (таблицы, данные, функции)
    │   └── extensions.sql        ← расширения (факт, версии, аудит)
    ├── scripts\                  ← init-db.ts, build-client.mjs
    ├── src\
    │   ├── server\               ← сервер (Express + TypeScript)
    │   └── client\               ← интерфейс (TypeScript)
    ├── public\                   ← index.html, styles.css, app.js (после сборки)
    └── README.md
```

Путь выбирайте **без пробелов и русских букв** (например `C:\Projects\normy-m`, а не `C:\Мои документы\...`).

## 1. Установите программы

| Программа | Версия | Где взять |
|---|---|---|
| Node.js | 18 или новее (LTS) | https://nodejs.org |
| PostgreSQL | 14 или новее | https://www.postgresql.org/download/ |

**Node.js:** обычная установка, всё по умолчанию. Проверка — откройте командную строку (Win+R → `cmd`) и выполните:
```
node -v
npm -v
```
Обе команды должны показать номер версии.

**PostgreSQL:** в установщике
1. оставьте компоненты по умолчанию (PostgreSQL Server, pgAdmin 4, Command Line Tools);
2. задайте пароль пользователю `postgres` — **запишите его**, он понадобится на шаге 4;
3. порт оставьте `5432`.

---

## 2. Распакуйте проект

1. Создайте папку `C:\Projects`.
2. Скачайте `normy-m.zip` и распакуйте его **в `C:\Projects`** (правый клик → «Извлечь всё…»).
3. Проверьте, что получилась папка `C:\Projects\normy-m`, а в ней сразу лежит `package.json`.
   Если файл лежит глубже (`C:\Projects\normy-m\normy-m\package.json`) — вложенность лишняя, берите внутреннюю папку.

---

## 3. Создайте пустую базу данных

Способ А — pgAdmin 4 (проще всего):
1. Запустите pgAdmin, введите пароль `postgres`.
2. Слева: Servers → PostgreSQL → правый клик по **Databases** → Create → Database…
3. Имя: `normy_m` → Save.

Способ Б — командная строка (Пуск → «SQL Shell (psql)», на все вопросы жмите Enter, затем введите пароль):
```sql
CREATE DATABASE normy_m;
```

Таблицы создавать руками **не нужно** — это сделает команда на шаге 5.

---

## 4. Настройте подключение (файл .env)

1. Откройте командную строку **в папке проекта**:
   откройте `C:\Projects\normy-m` в проводнике → в адресной строке напишите `cmd` → Enter.
2. Выполните:
   ```
   npm install
   copy .env.example .env
   ```
   (`npm install` скачает зависимости в папку `node_modules`, это занимает 1–2 минуты.)
3. Откройте файл `.env` в блокноте и замените значения:
   ```
   DATABASE_URL=postgresql://postgres:ВАШ_ПАРОЛЬ@localhost:5432/normy_m
   PORT=3000
   SESSION_SECRET=придумайте-любую-длинную-строку
   ```
   - `ВАШ_ПАРОЛЬ` — пароль пользователя `postgres` из шага 1.
   - Если в пароле есть спецсимволы, закодируйте их: `@` → `%40`, `#` → `%23`, `/` → `%2F`, `:` → `%3A`.

---

## 5. Создайте таблицы и данные

В той же командной строке (папка `normy-m`):
```
npm run db:init
```
Команда выполнит `db\BDScript.sql` (таблицы, демо-данные, view, функции, процедуры), затем `db\extensions.sql`. В конце появится `Готово.`

> Внимание: `npm run db:init` каждый раз **удаляет и пересоздаёт** таблицы. Повторно запускать его можно только если готовы потерять все данные.
> Чтобы применить только расширения, не трогая данные: `npm run db:init -- --ext`

---

## 6. Соберите и запустите

```
npm run build
npm start
```
В консоли появится `Нормы-М: http://localhost:3000`. Откройте этот адрес в браузере.

Консоль **не закрывайте** — пока она открыта, приложение работает. Остановка: `Ctrl + C`.

## 8. Повседневная работа

| Что нужно | Команда (в папке `normy-m`) |
|---|---|
| Запустить приложение | `npm start` |
| Режим разработки (автоперезапуск сервера и пересборка интерфейса) | `npm run dev` |
| Пересобрать после изменения кода | `npm run build` |
| Проверить типы | `npm run typecheck` |
| Сбросить БД к исходным данным | `npm run db:init` |

Где что менять:
- API и логика расчётов — `src\server\routes\*.ts`
- Подключение к БД — `src\server\db.ts`
- Страницы интерфейса — `src\client\pages\*.ts`
- Внешний вид — `public\styles.css`
- Структура БД — `db\BDScript.sql`, `db\extensions.sql`

## 9. Частые ошибки

| Сообщение | Причина и решение |
|---|---|
| `'npm' is not recognized` | Node.js не установлен или не перезапущена консоль — установите Node.js и откройте новое окно `cmd`. |
| `password authentication failed` | Неверный пароль в `DATABASE_URL` (`.env`). |
| `database "normy_m" does not exist` | Не создана БД — шаг 3. |
| `ECONNREFUSED 127.0.0.1:5432` / «Нет подключения к БД» | PostgreSQL не запущен: Win+R → `services.msc` → служба `postgresql-x64-…` → Запустить. |
| `EADDRINUSE: address already in use :::3000` | Порт занят — смените `PORT` в `.env` (например `3001`) и откройте `http://localhost:3001`. |
| Белая страница / нет стилей | Не выполнили `npm run build` (нет `public\app.js`). |
| Вход не проходит с `admin` / `admin123` | `db:init` не выполнялся или завершился с ошибкой — запустите его снова и прочитайте сообщение. |
| `Cannot find module …` | Не выполнен `npm install` или команда запущена не из папки `normy-m`. |

## 10. Linux / macOS

```bash
mkdir -p ~/projects && cd ~/projects
unzip ~/Downloads/normy-m.zip
cd normy-m
npm install
cp .env.example .env          # затем отредактируйте .env
createdb -U postgres normy_m
npm run db:init && npm run build && npm start
```
