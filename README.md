# Нормы-М — ИС «Нормы расходов материалов на изделие»

Расчётное задание по РиРП (ООО «МебельПро»). Node.js + TypeScript (Express, pg), фронтенд — TypeScript SPA в стиле Apple HIG (светлая/тёмная тема, сайдбар с «стеклом», листы, сегментированные контролы).

## Запуск

```bash
npm install
cp .env.example .env        # укажите DATABASE_URL своего PostgreSQL 14+ (пустая БД normy_m)
npm run db:init             # BDScript.sql + db/extensions.sql
npm run build
npm start                   # http://localhost:3000
```
Для разработки: `npm run dev`. Только расширения без пересоздания данных: `npm run db:init -- --ext`.

> `BDScript.sql` в начале удаляет и пересоздаёт таблицы — `db:init` без `--ext` стирает данные.

## Модули (по ТЗ)
- **Справочники** — материалы, изделия (дерево входимости), поставщики и цены, нормы кромки, форматы, единицы, статусы.
- **Расчёт норм** — карты раскроя (КИМ и подетальная норма 1/n автоматически), нормы кромки (`fn_edge_norm`), консолидация сводной нормы (`pr_consolidate_norms`), контроль полноты (запрос 6), пометка узлов «нужен перерасчёт».
- **Согласование и версионность** — черновик → на согласовании → утверждён → архив; каждая версия нормы/карты хранится, можно вернуться к предыдущей; история по изделию (запрос 5).
- **Программы и потребность** — `pr_calc_requirements`, округление листов вверх.
- **Документы** — сводная ведомость, план потребности, ЛЗК, калькуляция, план-факт; просмотр, печать, экспорт в Excel.
- **План-факт** — выпуск и расход вручную или импортом .xlsx (Шифр, Код материала, Списано, Цех), отклонение >5% подсвечивается, причины перерасхода.
- **Администрирование** — пользователи, роли, журнал аудита.
